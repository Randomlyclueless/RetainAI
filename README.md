# 🚀 RetainAI — Multi-Agent AI Customer Retention Intelligence Platform

RetainAI is an AI-powered customer churn prediction and retention intelligence platform designed to help businesses identify high-risk customers, understand churn reasons, and generate actionable retention strategies using Machine Learning, Explainable AI, and Multi-Agent Systems.

---

# 🌟 Features

## ✅ AI-Powered Customer Retention Intelligence
- Predict customer churn risk
- AI-generated churn explanations
- Retention strategy recommendations
- AI Copilot assistant
- Explainable AI using SHAP

---

# 🧠 Multi-Agent AI Architecture

RetainAI uses multiple intelligent AI agents:

| Agent | Responsibility |
|------|----------------|
| Prediction Agent | Predicts churn probability |
| Explanation Agent | Explains churn reasons |
| Recommendation Agent | Suggests retention strategies |
| Copilot Agent | Conversational AI business analyst |
| Monitoring Agent | Future real-time monitoring |

🚀 Frontend Setup (React)

Navigate to frontend
    cd frontend/my-app


Install dependencies
    npm install


Start frontend
    npm start


Frontend runs on:

http://localhost:3000


🚀 Backend Setup (Spring Boot)

Navigate to backend
    cd backend/backend


Start Spring Boot server
Windows (Git Bash)

    ./mvnw spring-boot:run


Windows CMD
    mvnw.cmd spring-boot:run


Backend runs on:

http://localhost:8080


🚀 AI Agent Setup (Flask)

Navigate to AI agent
    cd agent


Create virtual environment
    python -m venv venv


Activate virtual environment
Windows Git Bash

    source venv/Scripts/activate


Windows CMD

    venv\Scripts\activate


Install dependencies

    pip install -r requirements.txt


Start AI Agent Server
    python agent_api.py


AI server runs on:

http://localhost:5000


🛢️ MySQL Setup

Open MySQL

    mysql -u root -p


Create database

    CREATE DATABASE churn_db;
